## Overview

TAU-Agent is an agentic AI framework for understanding complex traffic anomalies in video. It combines retrieval-augmented generation, video captioning, object tracking, and vision-language models to identify relevant evidence before reasoning about an event. This query-driven approach supports anomaly detection, causal reasoning, temporal localization, and event explanation while remaining interpretable and scalable.

TAU-Agent achieved top-tier performance in the AI City Challenge 2026 and demonstrates strong generalization across multiple transportation video-understanding benchmarks.

## Environment

### Option 1: Docker (recommended)

Build the image:

```bash
docker build -f docker/Dockerfile.aicity -t tau-agent:latest .
```

This installs the pinned dependencies listed in [Dockerfile.aicity](docker/Dockerfile.aicity) on top of the `vllm/vllm-openai:v0.11.0` base image. It also installs the vendored [transformers](transformers), [trl](trl), and [qwen-vl-utils](qwen-vl-utils) packages in editable mode.

Run the container:

```bash
docker run --gpus all -it --rm \
  -v $(pwd):/workspace/TAU-Agent \
  -v /output:/output \
  -v /data:/data \
  --name tau_agent_run \
  tau-agent:latest /bin/bash
```

### Option 2: Local Environment

**Prerequisites:** [conda](https://docs.conda.io/en/latest/miniconda.html) (or Miniconda/Mamba), an NVIDIA GPU, and CUDA 12.8-compatible drivers.

1. Create and activate a conda environment with Python 3.12:

```bash
conda create -n tau-agent python=3.12 -y
conda activate tau-agent
```

2. Install the dependencies, including PyTorch and vLLM (see [requirements.txt](requirements.txt)):

```bash
pip install -r requirements.txt --extra-index-url https://download.pytorch.org/whl/cu128
pip install flash-attn==2.7.4.post1 --no-build-isolation
```

3. Install the vendored packages in editable mode:

```bash
pip install -e transformers
pip install -e trl
pip install -e qwen-vl-utils
```

## Usage

### End-to-End Example

For a single-command, end-to-end example (RAG evidence generation → formatted model input → fine-tuned Qwen3-VL inference → printed answer) on your own video/question, see [run_pipeline.py](run_pipeline.py):

> **Note:** The provided retrieval pipeline currently uses Modelsell and requires the `MODELSELL_API_KEY` environment variable. Other providers, including OpenRouter, OpenAI, and Gemini, can also be used with minor code adaptations for their API endpoints and credentials. Never commit API keys to the repository.

```bash
python run_pipeline.py \
    --video-path data/videos/tar_test/example.mp4 \
    --question "Does the gray sedan run the red light?" \
    --model-dir /output/model_checkpoint --lora
```

## Reproducing Results

### 1. Prepare the Data

The `data/` folder should look like:

```text
data/
├── captions/  # caption segments generated by the video captioning tool
├── dataset/   # dataset JSON files
├── RAG_Info/  # TAU-Agent generated RAG evidence
└── videos/    # video footage from the different datasets
```

The `captions`, `dataset`, and `RAG_Info` folders can be downloaded from our HuggingFace dataset repo: [TAU-Agent-Dataset](https://huggingface.co/datasets/yl4300/TAU-Agent-Dataset).

For videos, please place all source videos in the format `data/videos/{dataset_name}/xxx.mp4`, e.g.:

```text
data/videos/tar_test/v=-3nwOfm1Pdk_0-00_0-16.mp4
```

You should include data from the following datasets: Accident-Bench, barbados_traffic_challenge, FETV, HTV, PSI_VQA, so-tad, TAD, TAD-benchmark, tar_test, UCF-Crimes, and Vad-R1.

For details about the data and download instructions, see the [AI City Challenge 2026 Track 3 page](https://www.aicitychallenge.org/2026-track3/).

### 2. TAR_TEST

The inference stage is divided into five steps, including VLM inference and post-processing. Because the complete process can take a long time, intermediate results are included in the repository and can be used to start from any step. To reproduce the results without a GPU, run Step 5 directly.

For more details, see [eval/tar_test.sh](eval/tar_test.sh).

### 3. FETV

We include [eval/eval_fetv_rag_test.py](eval/eval_fetv_rag_test.py) to evaluate the FETV dataset.

Example run:

```bash
python eval/eval_fetv_rag_test.py \
  --model-dir /output/model_checkpoint --lora \
  --rag-dir data/RAG_Info/test/FETV \
  --clip-dir data/videos/FETV \
  --video-dir data/videos \
  --output-dir eval/output_fetv \
  --shard-rank 0 --shard-size 1
```
